# Mutants allowed to survive a mutation run, each with its reason
# (scripts/check-mutants.sh reads this).
#
# One mutant per line: its name as cargo-mutants prints it, without the line
# and column (they move with every edit above them), then " # " and the
# reason. For example:
#
#   crates/core/src/execution.rs: replace || with && in stop_groups # hangs: ...
#
# An entry covers every mutant in that file with that name. A pull request's
# run passes a listed mutant that was missed, timed out or was signalled (a
# signal ended cargo while it built the mutant or ran its tests). In the
# score, a listed mutant that timed out or was signalled counts as caught,
# because its reason says why the hang or the signal is how it fails; a
# listed mutant that was missed still counts as missed: listing a mutant lets
# a change through, it does not catch it.
